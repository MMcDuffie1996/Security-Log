This my take on what I believe should go into creating a security log from a security perspective. The core elements that I believed go into creating a security log are elements such as a timestamp, actor/user, emails linked to said user, status, roles, action, outcome, and priority. However, there are other elements/variables that would go into a security log such as Event ID/Log IDs, Session IDs, Source IPs/Host, and messages. For now, I just wanted this side project to concentrate on the beginner elements, because I would like to see if I can branch this project into something more efficient and user friendly.
